# 地牢密钥（Dungeon Keys）

3D 地牢解谜冒险微信小游戏（Roguelite）。每次进入随机生成的地牢：寻找钥匙、破解机关、躲避陷阱、与怪物战斗，解开出口封印后下楼，每通关一层三选一获得新能力。

**纯客户端**：无服务端、无外部资源。所有模型、贴图、特效、音效与音乐都在运行时由代码生成；存档保存在本地。

## 运行

- **微信开发者工具**：导入本目录 `wexin-test/DungeonKeys`，直接编译（`js/bundle.js` 已构建）。`game.json` 已开启 `iOSHighPerformance`（iOS 高性能模式，角色/怪物网格在运行时生成，需要 JIT 才流畅）。AppID 默认为测试号 `touristappid`，真机调试请换成自己的小游戏 AppID。
- **浏览器预览**：`node web/serve.mjs`，打开 http://localhost:8124/web/index.html（`wx-sim.html` 为模拟 `wx` API 的小游戏环境测试页）。键盘：WASD 移动 / J 攻击 / 空格 跳跃 / K 翻滚 / E 交互 / Q、R 技能 / Esc 暂停。
- **修改源码后**：`npm install && npm run build`

## 玩法

|---|---|
| 角色创建 | 开局选择熊熊英雄：4 种职业（骑士·挥砍+初始护盾 / 游侠·弓箭+快速翻滚 / 法师·追踪法球+初始火球 / 狂战士·范围劈砍+残血狂怒）、公熊/母熊（体型、睫毛腮红、裙装）、7 种毛色（含熊猫、北极熊、樱花熊）、6 种服装配色、8 种头饰、每种性别 4 款发型（公熊：短绒毛/狮子鬃毛/莫西干/络腮胡；母熊：齐刘海/高马尾/双丸子/麻花辫），可一键随机。角色为拟人化真熊造型：长吻、小眼、肩峰、圆肚、粗壮四肢、带爪大脚掌；身体由 SDF 基元平滑融合、Marching Cubes 生成一整块无缝网格，衣物是贴身外扩的一层皮，20 根骨骼 CPU 蒙皮（兼容 WebGL1）；公熊体型更壮、有肩峰和眉骨、吻部更长，母熊更苗条、大眼睫毛腮红、耳朵更大、裙装；接近 3D 动画电影的渲染：多层外壳毛发（毛茸茸的轮廓）、烘焙环境光遮蔽（脖子/腋下/吻部褶皱）、包裹光照 + 明暗交界暖色透光、菲涅尔轮廓光、光泽眼睛、织物纹理与金属高光；道具按熊掌比例缩小 |
| 写实熊模型（新） | 参考写实熊设定图重做：长吻、湿润黑鼻头、小而深的琥珀色眼睛（母熊大眼睫毛）、厚颊毛与肩峰、宽肩圆肚、黑色熊爪；四职业服装重做——骑士：绗缝内衬 + 带纹章胸甲 + 分层护肩 / 护臂 / 护膝 / 铁靴 + 随动作飘动的披风；游侠：敞怀连帽皮夹克 + 背心 + 斜挎带 + 腰包 / 小刀 / 箭袋 / 护腕 / 皮靴；法师：长袍 + 披肩领 + 绳腰带流苏 + 挂在腰上的书和药瓶；狂战士：毛皮披肩 + 皮裙 + 交叉皮带骷髅扣 + 缠布前臂 + 战纹。皮带扣、腰包等硬物沿身体表面投射贴合 |

| 角色动画 | 程序化全身动画：走路时重心左右转移、髋部起伏扭转、上身反向扭转、屈膝抬脚且脚掌贴地、手臂反向摆动；走/停平滑过渡；待机呼吸、重心摇摆、东张西望、眨眼、抖耳朵、摇尾巴；攻击为全身动作（横斩扭腰跨步、劈砍举过头下压蹲身、拉弓侧身后坐、施法前倾推掌）；敌人移动时前倾、转身侧倾 |
| 怪物造型 | 与主角同一套有机建模与动画电影材质：骷髅（完整骨架、肋骨笼、可开合下颌、眼窝红光、破盾锈剑）、兜帽骷髅弓手、半透明果冻史莱姆（流淌的底部、发光内核、高光大眼）、毛茸茸蝙蝠（带指骨的翼膜）、木板宝箱怪（金边、獠牙、舌头）、红伞白点蘑菇人（小手小脚）、半透明怨灵（破碎下摆、空洞兜帽）、骷髅冰法师、火焰小鬼（犄角、翼膜）、长满苔藓的岩石石魔、戴金冠的骷髅巫王；骨骼有光泽、岩石粗糙、史莱姆通透；部位为刚体挂在关节上（骷髅/蘑菇/石魔有走路动画），几何体按种类缓存共享，楼层加载时预生成 |
| 高度玩法 | 敌人会沿楼梯追上高台，但下不了悬崖；重击可把敌人打落深渊；跳起可躲地刺、火焰喷口和石魔的震地冲击波；弹道带垂直瞄准，高低差影响近战命中 |

## 3D 表现

- 房间氛围（新）：地面贴花（裂纹、污渍、苔藓、霜花、发光熔岩缝）、神殿 / 谜题 / 首领房地上的发光魔法阵；北墙挂饰（盾牌交叉剑、骷髅壁龛蜡烛、铁栅、发光符文、冰棱、熔岩脉）；烛台群（火苗摇曳 + 光源）、兵器架、木箱桶堆、断柱、宝藏房的金币宝石堆；从天花板裂缝斜照下的光柱与浮尘；贴地流动的雾；会乱窜、见人就逃的老鼠，苔藓遗迹的蝴蝶和萤火虫，地窖 / 熔岩层偶尔从头顶飞过的蝙蝠群

- three.js r162（兼容 WebGL1）；墙体、地面、台阶、悬崖侧壁、深渊井壁由格子高度图生成，烘焙环境光遮蔽（墙根、墙角、高台脚下更暗）
- 动态光源池：火把、火盆、符文、钥匙、陷阱火焰等几十个光源，按距离挑选最近的 3~5 个实时点光源；玩家自带提灯；月光方向光实时阴影随玩家移动
- 墙体剖切着色器：只镂空挡在镜头与角色之间的**墙**；地面、台阶、高台、深渊石柱、移动平台和所有能站上去的道具永远完整显示，跳上去不会消失。道具的外观高度与可站立高度一致
- 会坍塌的石柱：偏红褐的岩色 + 顶面发光裂纹 + 侧面缺口，一眼能区分；踩上去裂纹闪烁、抖动 0.9 秒后才塌，第一次踩到会提示，几秒后重新升起
- 迷雾探索：房间/走廊进入视野后才显示；小地图同步
- InstancedMesh 粒子（火焰、烟尘、碎骨、魔法、闪电）、加色光晕、冲击波、屏幕震动、命中停顿
- 画质三档（高/中/低）：分辨率、阴影、光源数量自动调整
